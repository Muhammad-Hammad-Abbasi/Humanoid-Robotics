**Priority**: Critical Fixes.

## Phase 1: Fix "Page Not Found" (Sidebar Repair)
1.  **Reset Sidebar Logic**:
    - **File**: `sidebars.ts` (or `.js`).
    - **Action**: Replace the ENTIRE content with this code to force auto-discovery:
      ```javascript
      const sidebars = {
        tutorialSidebar: [{type: 'autogenerated', dirName: '.'}],

      export default sidebars;
      ```

2.  **Verify File Names**:
